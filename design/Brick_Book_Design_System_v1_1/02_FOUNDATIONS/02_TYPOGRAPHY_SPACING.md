# BRICK BOOK — TYPOGRAPHY / SPACING / GEOMETRY v1.1

## Fonts
System sans only:
ui-sans-serif, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif

Mono:
"SFMono-Regular", Consolas, "Liberation Mono", monospace

Optional display serif:
Georgia, "Times New Roman", serif

## Type scale
display 40–48px — hero financial values
h1 28–32px — page title
h2 21–23px — section title
h3 18–19px — subsection
body-lg 17–18px — important text
body 15px — default reading text
body-dense 14px — lists/tables
metadata 13px — secondary information
label 11–12px — semantic labels

13px is valid for metadata, not dominant body copy.

## Money
Money uses mono + tabular numerals. Normal UI uses sans.

## Spacing
4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64px.

## Radius
6 / 10 / 14px. Do not introduce 16/20px radii globally.

## Touch
Minimum interactive target 44 × 44px.

## Density
Prefer 14–15px for dense transactional content rather than shrinking everything to 11–13px.

## Layout
Mobile gutter 16px. Desktop max content width approximately 1180px. Use whitespace for hierarchy, not giant empty blocks.
