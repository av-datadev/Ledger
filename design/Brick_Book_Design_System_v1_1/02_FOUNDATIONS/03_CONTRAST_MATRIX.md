# BRICK BOOK — CONTRAST QA

WCAG AA targets:
- Normal text ≥ 4.5:1
- Large text ≥ 3:1
- Important non-text UI boundaries target ≥ 3:1

Measure before release:
canvas/text, surface/text, brand fill/button text, positive/surface, negative/surface, warning/surface, focus/surface, input border/canvas.

Light and dark semantic accents are intentionally separate. Never reuse a dark-mode accent on light if it fails contrast.

Record measured ratios in repository QA notes.
