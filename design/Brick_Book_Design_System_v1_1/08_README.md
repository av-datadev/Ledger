# BRICK BOOK DESIGN SYSTEM v1.1

This package converts the strategy layer into an implementation-grade foundation.

Use the entire folder with Claude Design plus the existing Brick Book repository.

Recommended instruction:
"Treat this folder as the binding Brick Book design system. Read the Constitution, Do Not Invent, Foundations, Components, Patterns, Visual Reference Library and Quality Gate before designing or modifying UI. Inspect the existing implementation. Reuse its data model and behavior. Do not invent generic SaaS visuals."

Important decisions:
- Dark canvas = true #000000 AMOLED.
- Default body = 15px; dense = 14px; metadata = 13px.
- Money = mono + tabular numerals.
- Fonts = system stacks.
- Radius = 6/10/14px.
- Shipped paged 8-tab navigation is locked.

The visual-reference folder is intentionally a blueprint: the next step is to create actual rendered/Figma canonical screens and feed them back into this system.
