# READY-TO-USE CLAUDE PROMPTS

## Audit
Audit the existing Brick Book UI against this design system without modifying code. Rank violations by user impact. Check typography, contrast, card/surface overuse, navigation, financial hierarchy and mobile density.

## Foundations
Implement the Brick Book foundation tokens and shared primitives. Preserve behavior. Do not redesign individual screens yet.

## Dashboard
Redesign only the Owner Dashboard using the canonical specification and visual system. Preserve data/functionality. No new visual primitives. Lead with financial health, attention, breakdown and activity. Run the quality gate.

## Payment
Redesign New Payment with Amount as the hero. Keep Amount → Paid to → Purpose → Date. Scan/Speak/Write converge into one editable draft. Preserve offline behavior.

## BOQ
Redesign BOQ as a financial/procurement intelligence surface. Make billed, paid, due, ledger spend and variance understandable. Preserve BOQ/Stock relationships.

## Anti-generic
Before finalizing, remove anything that makes the screen look like generic SaaS/fintech. Prefer Brick Book-specific relationships, financial hierarchy and construction semantics.
