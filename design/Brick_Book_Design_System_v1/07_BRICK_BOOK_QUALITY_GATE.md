# BRICK BOOK — VISUAL QUALITY GATE v1.0

## Product identity
[ ] Could this screen only plausibly belong to Brick Book?
[ ] Does it feel solid, calm, precise and construction-specific?
[ ] Is it consistent with canonical screens?

## Hierarchy
[ ] Primary goal understood in 2 seconds?
[ ] Primary value visually dominant?
[ ] One obvious primary action?
[ ] Secondary actions quieter?

## Typography
[ ] Heading/body/metadata/labels distinct?
[ ] Body text comfortably readable?
[ ] Financial numbers tabular and aligned?
[ ] No unnecessary tiny text?

## Surfaces
[ ] Every surface has a purpose?
[ ] Could any card be removed?
[ ] Borders used selectively?
[ ] Tonal hierarchy does more work than outlines?

## Data
[ ] Easy to scan?
[ ] Large lists remain usable?
[ ] Empty/loading/error states designed?
[ ] High-frequency actions fast?

## Trust
[ ] Saved state clear?
[ ] Sync state clear?
[ ] Source documents traceable?
[ ] AI-extracted financial values reviewable?

## Interaction
[ ] Touch targets approximately 44px?
[ ] No essential hover-only interaction?
[ ] Destructive actions protected?
[ ] Contextual actions reduce clutter?

## Responsive
[ ] 320px works?
[ ] 390px works?
[ ] Tablet works?
[ ] Desktop works?
[ ] No accidental horizontal page scrolling?

## Accessibility
[ ] Light/dark contrast checked?
[ ] Color not the only state indicator?
[ ] Focus states?
[ ] Visible input labels?
[ ] Reduced motion?

## Anti-generic
[ ] No generic SaaS hero card.
[ ] No unnecessary gradient.
[ ] No purple AI treatment.
[ ] No random blue fintech styling.
[ ] No decorative chart without a decision.
[ ] No excessive rounded-card grid.
[ ] No "Dribbble shot" behavior that sacrifices usability.

## Final question
> If the Brick Book logo disappeared, would the design still feel like Brick Book?
If NO: reject and redesign.
